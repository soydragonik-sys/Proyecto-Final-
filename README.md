# 🌿 EcoShift: Simulador de Impacto Tecnológico en el Cambio Climático

¿Puede la línea de código correcta salvar el planeta?

EcoShift es una aplicación web interactiva desarrollada con Python (Flask) y HTML5 que simula cómo la optimización de algoritmos, la eficiencia energética en servidores (Green Coding) y la inteligencia artificial sostenible pueden frenar el calentamiento global de 2026 a 2050.

# 🛠️ Tecnologías Utilizadas

- Backend: Python 3.x, Flask

- Frontend: HTML5, Tailwind CSS, JavaScript (ES6+), Chart.js, FontAwesome

- Arquitectura: Aplicación Web Full-Stack ligera (Renderizado dinámico de plant
